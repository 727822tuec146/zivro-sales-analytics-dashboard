# ZivRO Sales & Analytics Dashboard

Power BI sales and analytics dashboard with KPIs, outlet analysis, item type insights and page navigation. Built with DAX and data modeling.

## Pages
- **Home:** KPI cards (Total Sales, Avg Sales, No of Items, Avg Rating) and the sales trend by outlet establishment year
- **Products:** Item Type, Fat Content and Fat by Outlet analysis
- **Customers:** Outlet Size and Outlet Location (Tier) analysis
- **Reports:** Outlet Type table with sales, items, rating and item visibility

## Key Insights
- Total sales: $1.20M across 8,523 items, with an average rating of 3.9
- Tier 3 outlets generate the highest sales (472.13K)
- Fruits and Vegetables and Snack Foods are the top item types by count
- Low Fat items account for 5.52K of the 8.52K items

## Tools Used
Power BI, DAX, Power Query

## Features
- Slicers for Outlet Location, Outlet Size and Item Type, synced across pages
- Custom sidebar with page navigation buttons
